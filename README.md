# PawsDex Adopcion de Mascotas
Es un sitio enfocado en la adopcion de animales con una maquetacion de interfaz tipo gamer.

# tecnologias utilizadas
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Google Fonts
- Formspree

# secciones del sitio
Inicio: Seccion principal con introduccion y boton de navegacion.
Mascotas: Tarjetas de animales en adopcion organizadas con Flexbox.
Resenas: Testimonios maquetados en cuadricula con CSS Grid e integracion de video.
Contacto: Formulario funcional conectado a Formspree para recibir mensajes por mail.
